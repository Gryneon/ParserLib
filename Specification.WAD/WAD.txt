//Spec:
// Double slashes are comments until newline '\n'
// :^key  MakeList Operator - Save this key in a collection.
// [*key] ForEach Operator - Extracts the value of the list key based on the iteration.
// [@key] GetLastItem Operator - Gets the last item saved of this collection
// :key   SaveTo Operator
// [key]  GetKeyValue Operator
// (num)  UseLiteral Operator

// Commands:
//   Read (Text|Int|Long|Short|Byte|Binary) <value> : <keyname> - Reads data and advances the cursor, stores it in <keyname>
//   Jump <value> - Sets the cursor to the position <value>
//   Save (Position|Length|Remaining|CountOf) [<value>] : <keyname> - Saves the specified property to a key

//   Read Text (<num>) : <keyname>                            - Reads <num> chars of text and stores it in <keyname>
//   Read Text [<keyname1>] : <keyname2>                      - Reads chars of text with the qty looking at <keyname1> for a value, stores in <keyname2>
//   Read Long : <keyname>                                    - Reads 8 bytes, stores in <keyname>
//   Read Int : <keyname>                                     - Reads 4 bytes, stores in <keyname>
//   Read Short : <keyname>                                   - Reads 2 bytes, stores in <keyname>
//   Read Byte : <keyname>                                    - Reads 1 byte, stores in <keyname>
//   Jump [keyname]                                           - Sets the cursor to the position stored in <keyname>
//   Jump [@keyname]                                          - Sets the cursor to the last position stored in the collection <keyname>
//   Jump (<num>)                                             - Sets the cursor to the position <num>
//   Loop Count (<num>)                                       - Loops <num> times
//   Loop Count [<keyname>]                                   - Loads the key <keyname> and Loops that many times
//   Loop Count [<keyname>] : <iteration>                     - Loads the key <keyname> and Loops that many times, storing the current iteration in <iteration>, 0 based.
//   Loop Each [*<keyname>] : <cursorname>                    - Loops the count of the collection <keyname>, and stores the value of that iteration of <keyname> in <cursorname>
//   Loop End                                                 - Either Ends or Repeats the loop based on the conditions of the loop
//   Loop Break                                               - Ends the loop
//   If [<keyname>] Is (<num>)                                - Begins Conditional if the value stored in <keyname> is equal to <num>
//   If End                                                   - Ends Conditional
//   Save Position : <keyname>                                - Saves the current cursor position in <keyname>




// Definition:

Read Text (4) : identification    // Reads 4 characters, store in key 'identification'
Read Int : numlumps               // Reads 4 bytes, store in key 'numlumps'
Read Int : diroffset              // Reads 4 bytes, store in key 'diroffset'
Jump [diroffset]                  // Sets the cursor to the position stored in key 'diroffset'
Loop Count [numlumps]
  Read Int : ^filepos
  Read Int : ^size
  Read Text (8) : ^name
  Save Position : savepos
  Jump [@filepos]
  Read Binary [@size] : ^data
  Jump [savepos]
Loop End
